## Explicitly Not Yet Accepted

The Ed25519 provider is currently a contract boundary only.

The current key generator deliberately does NOT claim that independently
generated byte arrays constitute a valid Ed25519 key pair.

A real cryptographic provider must be integrated before System 1 reaches
production acceptance.

## Security Boundary

Identity is not:

- MAC address
- IP address
- Hostname
- display name

Those are attributes.

The cryptographic identity is the trust anchor.
